## [0.1.0] — 2026-10-30

Первый рабочий MVP дашборда здоровья ИТ-проектов.

### Added

- **Дашборд направлений.** Карточки направлений с donut-диаграммой распределения
  проектов по статусам: «Проблема», «Внимание», «В работе», «Закрыт».
- **Карточки проектов.** Статус здоровья, направление, статус проекта, прогресс целей,
  плановая дата закрытия, просрочка, план/факт бюджета и причины проблем.
- **Расчёт здоровья проекта.** Правила на основе просрочки закрытия, перерасхода бюджета,
  статусов целей и приближения плановой даты.
- **Расчёт просрочки.** Просрочка в месяцах отдельно для проекта и для каждой цели.
- **Таблица всех целей.** Колонки: направление, проект, статус проекта, цель,
  статус достижения, плановая дата, просрочка.
- **Пять фильтров таблицы целей.** По направлению, проекту, статусу проекта,
  названию цели и статусу цели.
- **Главные фильтры.** По направлению и проекту с автоматическим сбросом
  несовместимой комбинации.
- **Загрузка Excel.** Поддержка `.xlsx` / `.xls`, чтение через SheetJS,
  drag-and-drop и выбор файла.
- **AI-структурирование Excel.** DeepSeek преобразует строки таблицы в JSON
  с проектами и целями; предусмотрена нормализация ответа.
- **Настройки DeepSeek.** Сохранение API-ключа в `localStorage`, проверка ключа,
  удаление ключа.
- **Чат по данным.** Вопросы к DeepSeek по текущему JSON дашборда с ответами
  на русском языке.
- **Демо-данные.** Набор из 9 проектов в трёх направлениях для работы без Excel.
- **Светлая и тёмная темы.** Автоматическое переключение через
  `prefers-color-scheme`.
- **Адаптивная сетка.** Карточки направлений и проектов подстраиваются под ширину экрана.
- **Стеклянный интерфейс.** Полупрозрачные карточки, blur, мягкие тени,
  анимации появления и hover-эффекты.
- **Модальное окно настроек.** Ключ, загрузка Excel, чат и статусные сообщения
  в одном месте.

### Changed

- План/факт бюджета отображается в миллионах с одним знаком после запятой.
- Даты в интерфейсе форматируются в `ru-RU`.
- При загрузке нового Excel фильтры сбрасываются на «Все».

### Fixed

- Экранирование пользовательских строк при рендере карточек и таблицы.
- Обработка ответа DeepSeek, обёрнутого в markdown-блок ```json.
- Защита от пустого файла и неподдерживаемого расширения при импорте.

### Known issues

- Данные и результаты импорта хранятся только в памяти и теряются после перезагрузки.
- API-ключ DeepSeek хранится в `localStorage` браузера — подходит только для локального использования.
- Нет предпросмотра и построчной валидации Excel перед применением.
- Правила светофора жёстко зашиты в `app.js`.
- Нет автотестов и CI.
- Таблица целей на узких экранах требует горизонтальной прокрутки.
- Нет экспорта в PDF/Excel и уведомлений.
