# Промпт для ИИ — TASK-003 «Сохранение данных и история загрузок»

> Приложи актуальные `app.js`, `data.js`, `Дашборд_5.html`, `styles.css`
> и `payload.json` из этой папки.

---

## Контекст

Дашборд «Здоровье ИТ-проектов» — статическое приложение на чистом HTML/CSS/JS.
Текущие данные лежат в `rawProjects` и после перезагрузки сбрасываются к `DEFAULT_PROJECTS`
из `data.js`. Уже есть импорт Excel через DeepSeek и API-ключ в `localStorage`
под ключом `deepseek_api_key`.

## Задача

Добавить слой сохранения состояния и историю импортов.

## Требования

### 1. Состояние

Сохранять в `localStorage` под ключом `dashboard_state_v1`:

```json
{
  "schemaVersion": 1,
  "updatedAt": "ISO-дата",
  "source": { "type": "demo | excel | manual", "fileName": "…", "importedAt": "…" },
  "filters": { "direction": "all", "project": "all" },
  "healthRules": {},
  "projects": []
}
```

- `projects` — массив в текущем формате `rawProjects`.
- Не сохранять вычисляемые поля: `health`, `reasons`, `overdueMonths`.
- Не дублировать `deepseek_api_key`.

### 2. Восстановление

- При старте: если состояние есть и `schemaVersion` актуален — использовать его.
- Если версия старая — выполнить миграцию.
- Если данных нет или они повреждены — показать демо-данные и бейдж «Демо-данные».
- Восстанавливать фильтры и правила светофора.

### 3. Автосохранение

- Debounce 300–500 мс после изменений.
- Индикатор в шапке: «Сохранено» / «Сохраняю…» / «Ошибка сохранения».
- Обрабатывать `QuotaExceededError`: показать сообщение и предложить экспорт JSON.

### 4. История

- Ключ `dashboard_history_v1`, максимум 10 снимков.
- Снимок: `id`, `createdAt`, `fileName`, `projectCount`, `state`.
- Список в модальном окне: дата, файл, количество проектов, кнопка «Восстановить».
- Восстановление — с подтверждением, после него состояние сохраняется как текущее.

### 5. Сброс и экспорт/импорт

- Кнопка «Сбросить к демо» с подтверждением.
- Экспорт текущего состояния в `dashboard-state-YYYY-MM-DD.json`.
- Импорт JSON: валидация схемы, предпросмотр количества проектов, подтверждение.
- Ошибки импорта — понятным текстом.

### 6. Синхронизация вкладок

- Слушать событие `storage` и обновлять состояние, если изменился `dashboard_state_v1`.
- Не зацикливать сохранение.

## Ограничения

- Без фреймворков и сборки.
- Не ломать существующие фильтры, таблицу целей, импорт Excel, чат DeepSeek.
- Не хранить API-ключ внутри общего состояния.
- Код — с комментариями на русском в неочевидных местах.
- Все пользовательские строки экранировать.
