# Промпт для ИИ — TASK-005 «Экспорт дашборда в PDF и Excel»

> Приложи `app.js`, `data.js`, `Дашборд_5.html`, `styles.css`.

---

## Контекст

Дашборд «Здоровье ИТ-проектов» — статическое приложение на чистом HTML/CSS/JS.
В `Дашборд_5.html` уже подключён SheetJS (`xlsx.full.min.js`). Данные проектов
хранятся в `rawProjects`, фильтры — в `currentDirectionFilter` и `currentProjectFilter`.
Таблица целей рендерится в `renderGoalsTable()`.

## Задача

Добавить экспорт текущего среза в PDF и Excel.

## Требования

### 1. UI

- Кнопка «📤 Экспорт» рядом с настройками.
- Меню или мини-диалог: «PDF», «Excel».
- Сообщение об успехе/ошибке.
- Если данных по фильтрам нет — экспорт недоступен с пояснением.

### 2. PDF

- Использовать `window.print()` и `@media print`.
- В печатной версии:
  - скрыть фильтры, кнопки, модальные окна, чат;
  - убрать `backdrop-filter`, тени, анимации;
  - белый фон, тёмный текст;
  - шапка: название, дата, активные фильтры, источник данных (если есть);
  - карточки направлений и проектов;
  - таблица целей;
  - `break-inside: avoid` для карточек;
  - `@page { size: A4; margin: 12mm; }`.
- Перед печатью добавить в документ блок с датой и фильтрами, после — убрать.

### 3. Excel

Создать книгу с тремя листами:

**Сводка**
- дата экспорта;
- фильтр по направлению;
- фильтр по проекту;
- количество проектов;
- количество красных/жёлтых/зелёных/закрытых.

**Проекты**
- Направление, Руководитель, Проект, Статус, Дата открытия, План закрытия,
  Факт закрытия, План бюджета, Факт бюджета, Здоровье, Просрочка (мес), Прогресс (%).

**Цели**
- Направление, Проект, Статус проекта, Цель, Статус цели, Плановая дата, Просрочка (мес).

- Использовать `XLSX.utils.json_to_sheet`, `XLSX.utils.book_new`, `XLSX.writeFile`.
- Задать ширины колонок через `ws['!cols']`.
- Даты — в формате `dd.mm.yyyy` или ISO, но не как произвольный текст.
- Числа — числами, не строками.
- Имя файла: `dashboard-YYYY-MM-DD[-filter].xlsx`.

### 4. Общие требования

- Экспорт берёт данные из отфильтрованных массивов, не парсит DOM.
- Не ломать текущий рендер и фильтры.
- Без новых тяжёлых зависимостей; SheetJS уже есть.
- Стили — в существующем стиле, светлая и тёмная темы.
- Код с комментариями на русском.

## Критерии приёмки

- [ ] Экспорт учитывает фильтры.
- [ ] PDF содержит шапку с датой и фильтрами.
- [ ] В PDF нет интерактивных элементов.
- [ ] Карточки не разрезаются между страницами.
- [ ] Excel содержит три листа.
- [ ] Даты и числа в Excel имеют правильные типы.
- [ ] Имя файла содержит дату.
- [ ] Есть сообщения об успехе и ошибке.
- [ ] Пустой срез не экспортируется.
- [ ] Тёмная тема не влияет на печатную версию.

## Формат ответа

1. Список изменённых файлов.
2. Новый модуль `export.js` (или функции в `app.js`) с полным кодом.
3. Патчи для HTML и CSS, включая `@media print`.
4. Чек-лист проверки в Chrome и Safari.
5. Ограничения и идеи для следующей версии.
