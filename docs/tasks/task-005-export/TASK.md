## User Story

> Я как руководитель, хочу выгрузить текущий срез в PDF, чтобы приложить его к отчёту
> или отправить коллегам.
>
> Я как аналитик, хочу выгружать проекты и цели в Excel, чтобы дальше анализировать их
> привычными инструментами.

## Зачем это нужно

Сейчас результат работы с дашбордом нельзя забрать с собой: ни отправить в чат,
ни приложить к презентации, ни продолжить анализ в Excel. Пользователю приходится
делать скриншоты, которые неудобно читать и невозможно фильтровать.

## Область работ

### Входит

- Кнопка «Экспорт» с выбором формата: PDF / Excel.
- Экспорт **текущего среза** с учётом активных фильтров.
- PDF:
  - шапка с датой, фильтрами и источником данных;
  - карточки направлений и проектов;
  - таблица целей;
  - читаемая печатная версия без кнопок и фильтров;
  - разрывы страниц, чтобы карточки не разрезались.
- Excel:
  - лист «Сводка»: дата, фильтры, количество проектов, распределение по статусам;
  - лист «Проекты»: направление, руководитель, проект, статус, даты, бюджеты, здоровье;
  - лист «Цели»: направление, проект, цель, статус, плановая дата, просрочка;
  - ширины колонок, числовые и датовые форматы.
- Имена файлов: `dashboard-2026-10-30-direction-A.pdf`, `dashboard-2026-10-30.xlsx`.
- Уведомление об успешном экспорте и об ошибке.

### Не входит

- Экспорт в Word/PowerPoint.
- Серверная генерация PDF.
- Отправка файла на email.
- Брендирование и шаблоны отчётов под разные аудитории.

## Сценарии

1. **PDF по всем проектам.** Пользователь нажимает «Экспорт → PDF», открывается
   системный диалог печати, можно сохранить в PDF.
2. **PDF по фильтру.** Выбрано направление «А» — в файл попадают только проекты «А»,
   в шапке указан фильтр.
3. **Excel с целями.** Пользователь выгружает Excel и видит три листа с корректными
   датами и числами.
4. **Пустой срез.** Если по фильтрам нет данных, экспорт блокируется с сообщением
   «Нет данных для экспорта».
5. **Ошибка.** Если библиотека Excel недоступна, показывается понятное сообщение.

## Критерии приёмки

- [ ] Экспорт учитывает активные фильтры.
- [ ] В PDF есть дата, фильтры и источник данных.
- [ ] В PDF нет кнопок, селектов и модальных окон.
- [ ] Карточки не разрезаются между страницами.
- [ ] Excel содержит листы «Сводка», «Проекты», «Цели».
- [ ] Даты в Excel остаются датами, суммы — числами.
- [ ] Имя файла содержит дату и фильтр.
- [ ] Есть сообщение об успехе и об ошибке.
- [ ] Экспорт не ломает текущий экран и фильтры.
- [ ] Работает в светлой и тёмной теме (PDF — светлая печатная версия).

## Технические заметки

- SheetJS уже подключён в `Дашборд_5.html` (`xlsx.full.min.js`) — использовать его
  для Excel, не добавлять новую библиотеку.
- Для PDF проще и надёжнее использовать `window.print()` + `@media print`:
  - скрыть `.header-right`, `.filters`, `.table-filters`, кнопки, модальные окна;
  - убрать тени и blur, сделать белый фон;
  - `break-inside: avoid` для карточек;
  - `@page { size: A4; margin: 12mm; }`.
- Если нужен «настоящий» PDF без диалога печати — добавить `html2pdf.js` только
  после согласования зависимости.
- Для Excel:
  - `XLSX.utils.json_to_sheet(rows)`;
  - `XLSX.utils.book_new()`, `book_append_sheet`;
  - `XLSX.writeFile(wb, fileName)`.
- Перед экспортом собирать данные из уже отфильтрованных массивов, не из DOM.
- Добавить в `styles.css` отдельный блок `@media print`.
- Кнопку экспорта разместить рядом с настройками, с иконкой 📤.

## Риски и открытые вопросы

- Brave/Safari могут по-разному печатать `backdrop-filter` — в печатной версии
  лучше полностью убрать эффекты.
- Большой портфель может занять много страниц; нужна ли нумерация и оглавление?
- Нужен ли экспорт только таблицы целей без карточек?
- Должен ли PDF включать AI-отчёт из task-004? Если да — задача зависит от неё.
- Нужна ли локализация форматов для других стран?
