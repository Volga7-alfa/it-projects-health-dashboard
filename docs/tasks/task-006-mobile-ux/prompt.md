# Промпт для ИИ — TASK-006 «Мобильный UX, фильтры в URL и поиск»

> Приложи `Дашборд_5.html`, `app.js`, `data.js`, `styles.css` и файлы из `mockups/`.

---

## Контекст

Дашборд «Здоровье ИТ-проектов» — статическое приложение на чистом HTML/CSS/JS.
Сейчас он оптимизирован под десктоп: фильтры в шапке, карточки в `grid`,
таблица целей с `min-width: 900px`. На телефоне интерфейс неудобен, а состояние
фильтров не сохраняется в ссылке.

## Задача

Сделать мобильную версию удобной и добавить управление срезом через URL,
поиск и сортировку таблицы целей.

## Требования

### 1. Адаптивность

- Брейкпоинты: 1200 px, 768 px, 480 px.
- На `< 768px`:
  - карточки в одну колонку;
  - фильтры скрыты в выдвижную панель;
  - кнопка «Фильтры» в шапке;
  - таблица целей прокручивается внутри контейнера, а не всей страницей.
- Кнопки и поля — минимум 44×44 px.
- Учесть `env(safe-area-inset-*)` для iPhone.
- Не должно быть горизонтального скролла `body` на 360 px.

### 2. Панель фильтров

- Открывается по кнопке, закрывается по «Применить», «Сбросить», Esc и клику по фону.
- Внутри — те же фильтры, что в шапке.
- Фокус-ловушка и `aria-expanded`.
- После применения панель закрывается, данные перерисовываются.

### 3. URL-состояние

- Параметры: `direction`, `project`, `q`, `sort`, `dir`.
- Не писать значения `all`, чтобы ссылка была короткой.
- При старте читать URL и применять состояние.
- При изменении фильтров/поиска/сортировки обновлять URL через `history.replaceState`.
- Кнопка «Скопировать ссылку» с подтверждением.
- Если в URL несуществующее значение — игнорировать и очищать параметр.

### 4. Поиск и сортировка таблицы целей

- Поле поиска над таблицей, placeholder «Поиск по цели…».
- Фильтрация по названию цели, регистронезависимая, с `toLocaleLowerCase('ru')`.
- Сортировка по клику на заголовок:
  - направление, проект, статус проекта, цель, статус цели, плановая дата, просрочка;
  - первый клик — по возрастанию, повторный — по убыванию;
  - показывать ▲/▼;
  - пустые даты — в конце.
- Сохранять сортировку в URL.

### 5. Мобильная таблица

- Липкая шапка таблицы.
- Тень или градиент у края, показывающий, что таблица прокручивается.
- На `< 480px` скрыть второстепенные колонки или сделать карточный режим
  (на твой выбор, обоснуй).
- Не ломать десктопную таблицу.

## Ограничения

- Без фреймворков и сборки.
- Не менять бизнес-логику расчёта здоровья.
- Не ломать импорт Excel, чат DeepSeek и существующие фильтры.
- Все пользовательские строки экранировать.
- Сохранить текущий визуальный стиль: стекло, скругления, светлая/тёмная темы.

## Критерии приёмки

- [ ] На 360 px нет горизонтального скролла страницы.
- [ ] Фильтры на мобильном работают через панель.
- [ ] Таблица прокручивается внутри контейнера.
- [ ] Поиск и сортировка работают.
- [ ] Состояние сохраняется в URL и восстанавливается.
- [ ] Ссылка копируется с подтверждением.
- [ ] Кнопки удобны для пальца.
- [ ] Десктоп не ухудшился.
- [ ] Обе темы корректны.

## Формат ответа

1. Список изменённых файлов.
2. Патчи HTML, CSS и JS.
3. Новый модуль `url-state.js` (или функции в `app.js`) с кодом.
4. Чек-лист проверки на 360, 768, 1024 и 1440 px.
5. Что осталось за рамками задачи.
