```text
│ │ Все                    ▾ │ │

└──────────────────────────────┘
```

## Таблица целей

- Контейнер с `overflow-x: auto`.
- Липкая шапка.
- Градиент у правого края, пока есть прокрутка.
- На 360 px видны: цель, статус, дата; остальное — в раскрывающейся строке.

## Поведение

- Кнопка «Фильтры» открывает панель снизу или справа.
- После «Применить» панель закрывается, URL обновляется.
- Кнопка «Ссылка» копирует текущий URL и показывает «Скопировано».
