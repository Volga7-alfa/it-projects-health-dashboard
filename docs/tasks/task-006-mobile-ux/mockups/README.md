# Mockups — TASK-006 «Мобильный UX»

Сюда складываем наброски и скриншоты мобильной версии.

## Что должно быть в папке

- `mobile-wireframe.md` — базовый набросок (уже есть).
- `filters-drawer.md` — панель фильтров.
- Скриншоты: `mobile-360.png`, `mobile-768.png`, `tablet-1024.png`.
- Скриншоты тёмной темы: `mobile-360-dark.png`.
- Схема URL-состояния: `url-state.md`.

## Требования

- Проверять на ширинах 360, 390, 768, 1024 и 1440 px.
- Все интерактивные элементы — не меньше 44×44 px.
- Никакого горизонтального скролла всей страницы.
- Таблица может прокручиваться внутри своего контейнера.
- Текст не меньше 14 px, заголовки — не меньше 18 px.
- Контраст текста и фона — не ниже WCAG AA.
