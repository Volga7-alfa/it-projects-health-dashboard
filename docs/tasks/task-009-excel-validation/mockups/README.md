# Mockups — TASK-009 «Импорт Excel»

Сюда складываем скриншоты и наброски окна проверки импорта.

## Что должно быть в папке

- `import-preview.md` — базовый набросок (уже есть).
- `error-state.png` — состояние с ошибками.
- `success-state.png` — успешный импорт.
- `mobile-preview.png` — мобильный вид.
- `dark-preview.png` — тёмная тема.

## Требования

- Видно количество проектов, целей, ошибок и предупреждений.
- Ошибки читаются без открытия файла: строка, колонка, причина, пример.
- Кнопка «Применить» визуально недоступна при критических ошибках.
- Никаких технических кодов вроде `INVALID_DATE` в основном тексте — только в деталях.
