## Состояния

| Состояние | Поведение |
|---|---|
| Ошибок нет | «Применить» активна, предупреждения не блокируют |
| Есть ошибки | «Применить» disabled, видна подсказка «Исправьте ошибки в файле» |
| Есть только предупреждения | Можно применить, но нужно подтверждение |
| Идёт разбор | Spinner, кнопки disabled |
| Ошибка чтения | Сообщение «Не удалось прочитать файл» |

## Мобильный вид

- Таблица проектов прокручивается горизонтально.
- Блок ошибок — карточками.
- Кнопки внизу закреплены, чтобы не искать их после длинного списка.
