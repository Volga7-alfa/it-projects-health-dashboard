## Состояния

| Состояние | Что показываем |
|---|---|
| Пустая форма | Поля пустые, кнопка «Войти» активна |
| Ошибка | Красная плашка под формой, поля не очищаются |
| Загрузка | Кнопка «Войти» с spinner, поля disabled |
| Успех | Переход на дашборд, имя и роль в шапке |
| Выход | Возврат на экран входа, сессия очищена |

## Мобильный вид

- Карточка входа занимает всю ширину минус 24 px.
- Поля и кнопка — высотой не меньше 44 px.
- Логотип и заголовок уменьшены, но остаются читаемыми.
