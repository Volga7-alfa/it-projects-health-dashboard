# Mockups — TASK-001 «Авторизация и роли»

Сюда складываем скриншоты, наброски и схемы UI для задачи.

## Что должно быть в папке

- `login-wireframe.md` — набросок экрана входа (уже есть).
- `admin-users-wireframe.md` — экран управления пользователями (добавить при проработке).
- Скриншоты финальной реализации — `login-desktop.png`, `login-mobile.png`,
  `admin-users.png`.
- Схема потока входа — `auth-flow.png` или `auth-flow.md`.

## Требования к макетам

- Светлая и тёмная темы.
- Десктоп от 1280 px и мобильный от 360 px.
- Состояния: пустая форма, ошибка входа, загрузка, успешный вход.
- Понятные подписи полей и кнопок на русском.
- Никаких «красных» технических ошибок вроде `401 Unauthorized` — только
  человеческий текст.
