# Правила светофора — набросок

```text
┌──────────────────────────────────────────────────────────────┐
│ Правила светофора                                       ✕   │
├──────────────────────────────────────────────────────────────┤
│ Пресеты:  [Строгий]  [Стандартный]  [Мягкий]                │
│                                                              │
│ Просрочка для красного, мес                                  │
│ ┌──────────┐  Сколько месяцев просрочки допустимо            │
│ │    1     │                                                 │
│ └──────────┘                                                 │
│                                                              │
│ Перерасход для красного, %                                   │
│ ┌──────────┐  0 = любой перерасход                           │
│ │    0     │                                                 │
│ └──────────┘                                                 │
│                                                              │
│ Жёлтый за N месяцев до закрытия                              │
│ ┌──────────┐                                                 │
│ │    3     │                                                 │
│ └──────────┘                                                 │
│                                                              │
│ Минимальный прогресс целей для жёлтого, %                    │
│ ┌──────────┐                                                 │
│ │    0     │                                                 │
│ └──────────┘                                                 │
│                                                              │
│ Просроченных целей для жёлтого                               │
│ ┌──────────┐                                                 │
│ │    0     │                                                 │
│ └──────────┘                                                 │
│                                                              │
│ [x] Перерасход у закрытого проекта считать красным           │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ Предпросмотр:                                                │
│ 🔴 2 → 3    🟡 1 → 1    🟢 5 → 4    ⚪ 2 → 2                  │
├──────────────────────────────────────────────────────────────┤
│ [Сбросить]                    [Отмена]      [Сохранить]      │
└──────────────────────────────────────────────────────────────┘
```

## Поведение

- Изменение поля сразу пересчитывает предпросмотр (без сохранения).
- «Сохранить» применяет правила и перерисовывает дашборд.
- «Отмена» возвращает значения, которые были до открытия.
- «Сбросить» возвращает стандартный пресет, но не сохраняет до нажатия «Сохранить».
- Ошибка: поле подсвечивается, под ним текст «Значение должно быть от 0 до 24».

## Мобильный вид

- Поля в одну колонку.
- Пресеты — горизонтальный скролл или две строки.
- Предпросмотр — компактные бейджи.
- Кнопки закреплены внизу.
